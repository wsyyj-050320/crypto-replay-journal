# Publishing Checklist

## Before Publishing

- Run `npm run format:check`.
- Run `npm run lint`.
- Run `npm run check`.
- Open `index.html`, `demo/index.html`, and `reports/daily-review-sample.html`.
- Confirm every public page includes "Not financial advice."
- Confirm launch copy does not imply trade instructions, performance certainty, copy trading, or managed execution.

## GitHub

- Use `assets/social-og.png` as the social preview.
- Use the README one-line pitch.
- Add screenshots from `assets/screenshots/`.
- Pin the sample report in the README.
- Open issues for roadmap items instead of claiming unfinished features are complete.

## Product Hunt

- First gallery image: `assets/social-og.png`.
- Second gallery image: `assets/screenshots/demo.png`.
- Third gallery image: `assets/screenshots/report.png`.
- Video: `video/crypto-replay-journal-promo-narrated.mp4`.
- Subtitles: `video/narration.srt`.

Recommended tagline:

> Review your crypto trades like a pro.

Short description:

> A paper trading and risk journal for crypto traders. Replay market moves, review exits, track drawdowns, and generate daily research reports.

## X / Twitter

Post sequence:

1. Product positioning post with `assets/social-og.png`.
2. Demo video post with `video/crypto-replay-journal-promo-narrated.mp4`.
3. Thread about why the project avoids directional trade calls.
4. Screenshot post showing the daily report.

## Reddit

Do not start with a link-only post.

Use an experience-first post:

> I turned my crypto trading bot into a paper trading and risk journal. Here is what I learned.

Only share the repo after explaining the problem, assumptions, and limitations.

## TradingView

Only publish educational risk-review indicators if needed later.

Do not use TradingView to promote paid strategy access, trade instructions, or external contact funnels.

## Payment

Early paid offers should be technical services:

- Local install help.
- VPS private deployment.
- Report customization.
- Data connector implementation.
- Dashboard customization.

Avoid early paid offers that look like financial advice, managed trading, copy trading, or strategy subscriptions.
